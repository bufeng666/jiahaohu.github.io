# jiahaohu.github.io

Jiahao Hu's personal academic homepage.

## Publish with GitHub Pages

1. Push this repository to GitHub with the repository name `jiahaohu.github.io`.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.

GitHub will publish the site at `https://jiahaohu.github.io` after the Pages workflow finishes. This site is plain HTML and CSS, so no build command or dependency installation is required.
